# Deep Dive 02 — Neural Networks

Animated, narration-synchronized explainer in five chapters (~17.5 min):

| # | Chapter | Narration |
|---|---------|-----------|
| 1 | What is the core idea behind modern AI? | 0:59 |
| 2 | One artificial neuron, step by step | 2:54 |
| 3 | From one neuron to layers | 2:21 |
| 4 | How does a network learn from examples? | 4:59 |
| 5 | Evolution, mutation and selection (neuroevolution + Snake) | 6:12 |

Run `npm run dev` from the repository root and open `/series/neural-networks/`.
Chapters play back-to-back; the rail jumps between them.

## How the animation is built

The film is one 1920×1080 SVG stage (`index.html` → `#stage`) over a subtle
Three.js depth-field background. Each chapter module (`src/ch1.js` … `src/ch5.js`)
builds its objects once and returns `update(t)`, a pure function of the active
narration clip's time. There is no CSS animation or `Math.random`, so seeking,
pausing and frame-by-frame export reconstruct identical frames.

**Every visual beat is keyed to the exact spoken words.** Cues are looked up by
phrase, e.g. `cue.at('set all three weights')`, from word-level timings in
`src/timing-data.js`. That file is generated by forced alignment of the narration
audio against the approved script:

```bash
pip install pocketsphinx   # bundles its English acoustic model; no download needed
python3 scripts/align-neural-networks.py
```

If the narration is regenerated, re-run the script; the animation follows the new
timings automatically. A phrase that no longer exists in the script throws a clear
error on load.

Sentence-by-sentence visual mapping: [`storyboard.md`](./storyboard.md).

## QA / export hooks

- `window.renderAt(seconds, chapterIndex)` — render any moment (0-based chapter).
- `window.renderFrame(frame, chapterIndex)` — same, at 24 fps frame numbers.
- `window.chapterDurations` — per-chapter durations (last word + 1.2 s hold).

Review captions (with the current word highlighted) sit below the film frame, not in it.
