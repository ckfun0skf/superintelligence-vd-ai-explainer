# Part 02 — Historical visual references

## Mark I Perceptron

The Chapter 1 preview uses [smithsonian-mark-i-perceptron-reference.jpg](./smithsonian-mark-i-perceptron-reference.jpg), a 799×629 image of the Mark I Perceptron in a brief inset. It is not used as a full-frame 1080p plate.

The [Smithsonian National Museum of American History object record](https://americanhistory.si.edu/collections/object/nmah_334414) identifies the machine as the Mark I Perceptron, built in 1958 at Cornell Aeronautical Laboratory, and displays “CC0 Usage Conditions Apply.” The museum’s [Rights and Reproductions page](https://americanhistory.si.edu/collections/about/rights-and-reproductions) says Open Access images marked CC0 may be used for any purpose, including commercial use, without permission. Smithsonian [Terms of Use](https://www.si.edu/termsofuse) note that CC0 addresses copyright only and does not guarantee freedom from every possible third-party right.

For the image credit, the museum asks users to cite it as from the collection of the **National Museum of American History, Smithsonian Institution**. The preview includes that credit beside the inset and links it to the object record. Do not imply Smithsonian sponsorship or endorsement. If the individual downloadable file presents a separate restriction beyond the object-page CC0 status, replace it with an original stylized reconstruction before release.
