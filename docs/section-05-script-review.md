## Approved narration

Suppose our itinerary needs current transit times or opening hours. The model may not have reliable live information in the conversation, so the AI product can provide tools to help.

A tool is a separate piece of software—a map, a search service, a calendar, or a booking system. The people who build the AI product decide which tools are available and define how each one works: what it can do, what information it needs, and what result it returns.

They can also set rules about permission. For example, a booking tool may require your approval before it confirms a reservation.

The model cannot call any tool it imagines. It can choose only from the tools the application has made available.

5. **Land the distinction:** The model is visually connected only to the tools exposed by the application. An imagined, unavailable tool is blocked at the boundary.
