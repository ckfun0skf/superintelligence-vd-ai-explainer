## Interaction pattern observed in the reference

The reference uses a compact, collapsible, horizontally scrollable chapter rail below the timeline. Each chapter is a button with a `data-time`; selecting one seeks the audio and reconstructs the corresponding deterministic frame. The active chapter follows playback time. The chapter toggle can collapse the rail in compact landscape layouts.

This is a player-interaction reference only. No visual or audio assets from the reference project are copied into this project.
