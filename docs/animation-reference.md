# Animation reference notes

**User-provided visual reference:** [Facebook reel by Graduateml](https://www.facebook.com/share/r/1KAagFaGar/) (resolved to [the public reel](https://www.facebook.com/reel/2327253598113055/)). Viewed on 2026-10-18.

## Visual language observed

The reel uses a near-black, dark-mode canvas; high-contrast text; restrained color coding; and a progression from concrete words to token groupings, vector diagrams, attention connections, and model schematics. Equations are linked to motion rather than left as static decoration. Thin grids, clean labels, small glowing accents, and measured changes in scale make abstract operations feel spatial.

## Adaptation for this explainer

The project borrows only the general motion-design principles: dark contrast, legible color-coded diagrams, and progressive abstraction. Section 01 starts with a familiar AI chat interface that assembles before the narration, then shows the user's words being typed and an answer appearing. Later sections will use the same visual system to explain tokens, attention, model training, and tools. No scenes, script, music, or assets are copied from the reference.
